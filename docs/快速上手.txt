截图提醒（便携版） 快速上手
================================

【1】双击 截图提醒.exe
     首次会问「数据存哪块盘」→ 选盘 → 自动建 D:\截图提醒（可改）
     之后图标在右下角托盘，桌面不会多出一堆文件夹

【2】按 Ctrl + Alt + S  →  拖鼠标框选  →  松手
     不拖直接回车 = 截整个屏幕；按 W = 截当前窗口；Esc 或右键 = 取消

【3】面板顶部有「快捷提醒」：1 小时 / 3 小时 / 24 小时 / 下班前
     点一下就直接排好并关闭，不用再设
     面板底部可直接「框选 / 箭头 / 圈选」进入标注
     标注里 Ctrl+Z 撤销、Ctrl+Y 重做；标完发现错了按「还原」重来
     右下「设置提醒…」才需要填时间、重复、备注

【4】到点弹窗：滚轮缩放（跟光标）、拖动平移、双击切 1:1、R 旋转     · 已知晓/已完成  → 这条结束（重复任务自动排下一次）
     · 稍后提醒       → 5/15/30/60 分钟或自定义
     · 设置下一次提醒  → 改个时间接着提醒
     关闭窗口 = 稍后 15 分钟（防止误关丢失）

【5】双击托盘图标 = 任务列表（右键可改期/跳过/删除/立即提醒）
     托盘右键 = 日历视图 / 设置 / 暂停全部 / 打开数据目录 / 退出

小贴士
 · 只带一个 exe 就能换电脑用；数据在你自己选的盘里
 · 想换位置：托盘右键 → 设置 → 数据 → 更改位置
 · 快捷键随便录：Ctrl+Alt、Ctrl+Alt+S、A+S、Ctrl+Shift+F1 都行（最多4键）
 · 「设置提醒」「设置」两个窗口可以拖动边缘放大，字会跟着变大
 · 快捷键被占用？录制完保存时会自动检测并提示
 · 有怪问题：命令行跑  截图提醒.exe --check
   会在 logs 目录生成诊断报告
 · 忘密码：记事本打开 data\config.json，把 passwordHash 与
   passwordSalt 改成 null，保存重启

详细说明见 docs\使用说明.md
