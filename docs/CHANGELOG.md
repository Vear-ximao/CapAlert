# 版本变更

## v1.3.2（2026-11-18）稳定性与体验优化

这一版没有加新功能，重点是把「提醒的时间逻辑」彻底修对，并把界面统一到一套视觉语言。
核心原则：**你设定的时刻，永远不会被悄悄改掉。**

1. **修复「设置下一次提醒」点了没反应**：这个按钮此前实际执行的是「稍后 15 分钟」，
   设置对话框根本不会出现。现在点它会正常弹出设置框（原图延续，不复制文件）。
2. **修复稍后提醒 / 睡眠唤醒后的连环弹窗**：过去「每隔 5 分钟」的任务点「稍后 15 分钟」，
   再点「已知晓」，下一次会算到过去、立刻又弹。现在下一次严格晚于当前时刻，
   错过的时间点直接跳过，不会连环炸屏。
3. **修复免打扰顺延把时刻永久改掉**：设「每天 13:52」又开免打扰，某次被顺延后，
   重复时刻会被永久改成顺延后的时间。现在把「计划时刻」与「本次生效时刻」分开，
   顺延只影响这一次，下一次仍按你设的 13:52。
4. **修复数据文件半损坏就崩主界面**：`tasks.json` 里个别字段为 `null` 时，任务列表会直接抛异常。
   现在加载即做净化，坏字段按默认值兜底。
5. **标注后误关面板不再丢成果**：有标注时关闭处理面板（含 `Alt+F4`）会二次确认，
   并提供三个选项：丢弃 / 只存图不设提醒 / 返回继续编辑。
6. **多条提醒同时到期不再硬塞**：弹窗显示「第 X / 共 N 个」并提供「全部稍后」；
   提醒强度按队列自动降级，不再连续几个全屏遮罩轮番糊脸。
7. **关闭弹窗的顺延分钟数跟随设置**：原来硬编码 15 分钟，现在用你在设置里填的值。
8. **截图前改为最小化自身窗口**：原来直接隐藏，按 `W` 截当前窗口会截错目标；
   改为最小化既避免截到自己，又不影响前台窗口判定。
9. **更稳的数据与备份**：备份还原增加路径越界校验与失败回滚；还原后配置会重新加载；
   写盘失败会在托盘红字提示，不再「内存显示成功、磁盘其实没写」。
10. **诊断不再有副作用**：`--check` 全程使用独立临时目录，不再回写你的真实配置；
    `--check-ui` 不再改动开机自启快捷方式；退出码真实反映结果。
11. **热键与自启更可靠**：组合键半按状态在失焦/超时后清理，避免误触发；
    开机自启以配置为准，快捷方式被误删会自动重建。

### 界面

- 统一视觉语言：圆角、三级字阶、统一的按钮主次层级；说明文字对比度提高。
- 任务列表新增空状态引导（不再是空白页），提示 `Ctrl+Alt+S` 开始第一张截图。
- 到点提醒的三出口按主次重排；原图丢失时给出明确的虚线框与行动指引（不再是深底小字）。
- 字体改为静态缓存，修复长时间运行反复新建字体导致的 GDI 句柄累积。
- **全新品牌图标**：图片框 + 铃铛 + 时钟，7 档尺寸；16/24px 单独做了简化母版，托盘小图标不糊。

### 自检

- 自检断言从 80 项扩充到 **148 项**，新增覆盖：三参数「下一次」计算、出口状态流转、
  免打扰锚点不漂移、脏数据容错、备份越界拒绝与回滚、落盘失败告警。

## v1.3.1（2026-11-16）标注可撤销

1. **`Ctrl+Z` 撤销**所有标注动作（框选、箭头、圈选、文字、马赛克一视同仁，按笔回退）。
   原来挂在窗体 `OnKeyDown` 上，焦点落在按钮上会收不到；改走 `ProcessCmdKey`，
   并在点画布时主动拿焦点，快捷键稳定生效。
2. **`Ctrl+Y` / `Ctrl+Shift+Z` 重做**，撤销撤多了不用重画；画了新的一笔会自动清空重做栈。
3. `Ctrl+Delete` 清空全部；`Esc` 退出。
4. 工具条新增「重做」，`撤销/重做/清空` 按状态自动置灰。
5. 处理面板新增 **`还原`**：标完点了「完成」才发现标错，一键退回未标注原图重来（不必重新截图）。
6. 自检模式新增撤销/重做实测断言（新增 3 → 撤 2 → 撤 1 → 重做 2 → 清空 0）。

## v1.3.0（2026-11-16）处理面板补快捷入口

截图完成面板原来有大片空白，现在都填成了常用动作：

1. **顶部加快捷提醒**：`1 小时后` / `3 小时后` / `24 小时后` / `下班前 18:00`，
   点一下**直接保存并排好提醒**，不再弹设置框（想加备注、设重复仍走「设置提醒…」）。
   「下班前」用的时刻可在设置里改；如果今天这个点已经过了，自动排到明天同一时刻。
2. **底部加标注直入按钮**：`框选` / `箭头` / `圈选`，点哪个就以哪个工具进入标注，
   省掉进去再选工具的一步（进去后仍可切文字、马赛克）。
3. **新增「圈选」工具**：按住鼠标随手画一圈即可圈住任意形状，不需要画标准图形。
4. 设置 → 其他 新增「下班时间」一项（默认 `18:00`）。

## v1.2.0（2026-11-16）快捷键与存放位置

1. **快捷键不再限制两键**：原来的「修饰键+键 / 任意两键」二选一模式取消，
   改成直接录一串按键（最多 4 个），程序自动选实现方式：
   - 若干修饰键 + 1 个普通键（如 Ctrl+Alt+S）→ 系统注册，最稳，可事前检测占用；
   - 多字母（A+S）或纯修饰键（Ctrl+Alt）→ 键盘钩子，保存时明确提示代价。
   录制界面实时显示已录的键，保存前统一校验（至少两键、冲突检测）。
2. **数据不再堆在 exe 旁边**：首次启动弹出「选数据存放位置」，选盘符后自动建
   `<盘>:\截图提醒\`，所有截图/任务/日志/备份都在里面；exe 旁只留一个几十字节的
   `截图提醒-数据位置.txt` 指路。
3. **设置里可「更改位置」**：复制现有数据到新盘并切换，原位置文件保留不删。
4. **旧版数据自动提示迁移**：首次选择位置时，若检测到 exe 同目录还有旧 data/shots，
   会多一个勾选框，可顺手搬过去。
5. 诊断模式（`--check` / `--render-test`）在未配置数据目录时自动改用临时目录，
   不再往程序目录里写文件。

## v1.1.0（2026-11-16）体验修正版

按实际使用反馈修的 5 个点：

1. **「设置提醒」「设置」支持自定义缩放**：两个窗口改为可拖动调整大小，内容整体等比缩放（1.0×–2.6×），
   字小的机器上直接把窗口拉大即可。缩放按「设计坐标快照」重算，反复拉伸不会积累偏移；字体走缓存，不会耗尽 GDI 句柄。
2. **重复规则说明改成大白话**：底部预览从原来一句「之后：每隔 1 天」改成 3–5 行，
   写死「第一次几点、之后固定在这个时刻、下一次具体几号几点、结束条件」，
   消除「重复的是今天这个时间段，还是明天这个时间点 +10 分钟」的歧义。
3. **结束条件按需显示**：「重复 = 不重复」时整行隐藏；各重复类型的选项区高度按内容收缩，
   顺带消掉了原来中间那一大片空白。
4. **修「指定具体时间」标签页被裁切**：加高标签页区域并重排内容，日历框、提示、「明天此时 / 今天 20:00」
   不再被页签边框切掉。
5. **截图后未主动保存即不落盘**：处理面板直接关窗 = 丢弃（不再默认存一张图），
   面板右上角常驻提示「关闭窗口 = 丢弃本次截图」。

另：布局改为「从上到下顺序堆叠」自动计算高度，窗口高度随内容变化，不再有固定像素造成的空隙。

## v1.0.0（2026-11-16）首个正式版

**技术形态**
- C# / .NET 8 WinForms，单文件自包含发布（66.4 MB），目标机无需安装 .NET 运行时
- Per-Monitor V2 DPI 感知，截图按物理像素裁切
- 全便携：所有读写限于程序目录，不写注册表、不写 AppData（开机自启的快捷方式除外）

**核心功能（14 项）**
1. 全局快捷键触发截图，可自定义，保存前探测冲突
2. 截图处理面板：标注 / 复制 / 仅保存 / 设提醒 / 丢弃
3. 区域框选（冻结画面 + 尺寸显示），回车截整屏
4. 多屏虚拟桌面抓屏，抓屏前自动隐藏自身窗口
5. 相对时间提醒（N 分钟/小时）
6. 绝对时间提醒（年月日时分）
7. 六种重复规则：不重复 / 每隔 N / 每天 / 每周 / 每月 / 指定月份
8. 结束条件：永不 / 截止日 / 共 N 次
9. 任务持久化 + 睡眠唤醒后漏提醒补弹一次
10. 置顶提醒弹窗（原图 + 备注 + 距截图天数）
11. 原图 PNG 无损保存，永不重编码
12. 缩放查看：滚轮跟光标、10%–800%、双击 1:1、拖拽平移
13. 三出口：已知晓 / 稍后提醒 / 设置下一次
14. 托盘常驻 + 单实例 + 任务列表 + 便携隔离 + 使用说明

**可选增强（13 项，全部实现）**
- O-01 截图标注：矩形 / 箭头 / 文字 / 马赛克，标注后原图另存 *.orig.png
- O-02 截图自动复制到剪贴板
- O-05 提前预提醒（托盘轻提示）
- O-06 日历视图（月历标记 + 当天清单）
- O-07 免打扰时段（跨零点，顺延到时段结束）
- O-08 批量操作（暂停全部 / 全部顺延 1 天 / 跳过下一次）
- O-10 一键备份与还原（zip）
- O-11 主界面密码（PBKDF2-SHA256 加盐，只锁界面）
- O-12 看图增强（上/下一张、旋转、快捷键缩放）
- O-13 热键冲突自检
- O-14 开机自启（启动文件夹快捷方式 + 路径失效自检修复）
- O-15 活动窗口截图（框选界面按 W，直接用冻结画面裁切窗口矩形）
- O-16 历史与统计（近 30 天提醒次数、已知晓次数、按期完成率）

**验证记录**
- 逻辑自检 63 项全部通过（重复规则含月末/闰年/跨年边界、数据损坏恢复、路径规则、免打扰跨零点、密码、备份还原）
- 打包后诊断：目录可写、配置读写、任务加载、快捷键可注册、1920×1080 抓屏非空白、PNG 落盘回读尺寸一致 —— 全部 PASS
- 装配自检：托盘 + 热键 + 调度器启动 2 秒后干净退出，日志无异常
