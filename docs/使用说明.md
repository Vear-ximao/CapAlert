# 截图提醒（便携版）· 使用说明

版本 1.0.0　·　单文件绿色版，无需安装、无需联网、不写注册表

---

## 1. 这是什么

按一下快捷键，框选屏幕上的任意区域截一张图，然后指定「什么时候提醒我看它」。到点会把**原图按原始像素**弹到你面前，可以放大缩小看清细节；看完点「已知晓」，也可以顺手定下一次。

典型用法：把客户改稿意见、报错截图、配色方案截下来，设成「今晚 9 点」「每周一三五上午 10 点」「每月 1 号」再提醒自己。

---

## 2. 第一次启动

1. 把 `截图提醒.exe`（和 `docs` 文件夹，可选）放到任意位置：桌面、D 盘、U 盘都行。
2. 双击 `截图提醒.exe`。
3. **第一次会问你把数据存在哪块盘**：
   - 选盘符 → 自动填成 `D:\截图提醒` 这样的路径（也可以点「浏览…」自己挑文件夹）；
   - 点「就用这个位置」→ 程序在该位置建好 data / shots / logs / backups，以后所有截图、任务、日志都在里面；
   - 如果检测到旧版数据，会多一个勾选框，可顺手把老截图一起搬过去。
4. 程序**没有主窗口**，会缩在右下角托盘区（蓝色圆形小图标），首次启动弹一条托盘提示。
5. 如果刚才选了「退出」，程序不会创建任何文件，下次启动会重新问。

> 程序本体只有一个 exe，**不会在桌面铺一堆文件夹**。exe 旁边只会多一个几十字节的
> `截图提醒-数据位置.txt`，里面就一行：数据放在哪。删掉它，下次启动会重新问。

> 想换位置：托盘右键 → 设置 → 数据 → 更改位置…（会复制现有数据，原位置不删）。

## 3. 主流程：截图 → 定提醒

### 3.1 截图

| 操作 | 说明 |
|---|---|
| 按 `Ctrl + Alt + S` | 默认快捷键，进入框选状态（可在设置里改成任意组合） |
| 拖动鼠标 | 框选要截的区域，右上角显示 `宽 × 高` |
| 松手 | 立即确认选区 |
| 直接按 `Enter` | 不拖拽时截取**整个屏幕** |
| 按 `W` | 截取**当前窗口**（自动贴合窗口边框，不用手描） |
| 按 `Esc` 或点右键 | 取消本次截图 |
| 单击一下 | 不产生选区，继续等待拖拽 |

截图时会先把自己程序的窗口藏起来 150 毫秒，避免截到自己。

### 3.2 处理面板

**顶部「快捷提醒」**——点一下就直接排好提醒并关闭面板，不再弹设置框：

| 按钮 | 排到什么时候 |
|---|---|
| `1 小时后` / `3 小时后` / `24 小时后` | 当前时间往后推 |
| `下班前 18:00` | 今天这个时刻；如果已经过了，就排到明天同一时刻（时刻可在设置 → 下班时间里改） |

> 快捷按钮排出来的是「只提醒一次、无备注」。想加备注或设重复，用右下角的「设置提醒…」。

**底部按钮**

| 按钮 | 作用 | 快捷键 |
|---|---|---|
| 框选 | 进入标注，直接是画矩形框 | `Ctrl+A` |
| 箭头 | 进入标注，直接是画箭头 | — |
| 圈选 | 进入标注，直接是手绘自由圈 | — |
| 复制 | 复制当前图到剪贴板 | `Ctrl+C` |
| 还原 | 标注标错了，退回未标注的原图重新标（标过之后才可点） | — |
| 丢弃 | 不保存，直接丢掉 | `Delete` |
| 仅保存 | 存进 `shots\` 目录，不设提醒 | `Ctrl+S` |
| 设置提醒… | 保存 + 打开完整设置（时间/重复/备注） | `Ctrl+R` |

> 三个标注按钮只是**进去时用的工具不同**，进去后仍可随时切到文字、马赛克。
> **直接关掉这个窗口 = 丢弃本次截图**（磁盘上不留任何文件）。

如果设置里开了「截图后自动复制到剪贴板」，面板一打开图就已经在剪贴板里了。

### 3.3 标注

- **框选**：拖出一个红矩形框
- **箭头**：从起点拖到终点，箭头在终点
- **圈选**：按住鼠标随手画一圈（不用管圆不圆），松手即成型
- **文字**：点一下图上位置，再输入文字（回车确认）
- **马赛克**：拖出要打码的区域
- `撤销` 去掉最后一笔，`重做` 反悔，`清空` 清掉全部
- 快捷键：`Ctrl+Z` 撤销、`Ctrl+Y`（或 `Ctrl+Shift+Z`）重做、`Ctrl+Delete` 清空、`Esc` 退出
- 标完点了「完成」才发现标错？回处理面板点 `还原`，退回未标注的原图重来
- 标注会**烧进保存的那张图**；原图会另存一份 `xxx.orig.png`，方便回溯「我当初截的是什么」

### 3.4 设提醒

**时间**（两个标签页二选一）

- 「多少分钟 / 小时后」：填数字选单位，或用 `+5 分钟`、`+15 分钟`、`+30 分钟`、`+1 小时`、`+3 小时` 快捷按钮
- 「指定具体时间」：日历选日期，时刻用键盘改（24 小时制，精确到分）；配 `明天此时`、`今天 20:00` 快捷按钮

**重复**（6 种）

| 选项 | 含义 | 边界处理 |
|---|---|---|
| 不重复 | 只提醒一次 | — |
| 每隔 N 分钟 / 小时 / 天 | 固定周期，从本次提醒时间起算 | — |
| 每天 | 每天都在同一时刻 | — |
| 每周 | 勾选周一至周日，可多选 | 至少勾一天 |
| 每月 | 每月某日（1–31） | 选 31 号而该月没有 31 号 → 自动落到当月最后一天（2 月落到 28/29 号） |
| 指定月份 | 每年勾选的若干月份的某日 | 至少勾一个月；跨年自动回绕 |

**结束条件**：永不结束 / 截止到某天 / 共执行 N 次
> 只有选了「重复」才会出现这一行；选「不重复」时整行隐藏，不会占地方。

**提前预提醒**：填 N 分钟（0 = 关）。到点前 N 分钟先在托盘轻提示一次，不会打断你。

**备注**：一句话说明，例如「看这个红色块是不是配错了」。弹窗顶部会醒目标出来。

底部蓝色预览框把「这次到底会怎么提醒」写成大白话，三到五行：

```
第一次提醒：2026-11-16 13:52
之后：每隔 1 天提醒一次，每次都固定在 13:52 这个时刻
下一次：2026-11-17 13:52
结束：共提醒 5 次（含这次）
```

重点看「之后」和「下一次」两行：重复用的是**你设定的那个时刻**（13:52），
不是「明天现在 +10 分钟」。各类型分别是：

| 重复类型 | 预览里怎么写的 |
|---|---|
| 每隔 N 天 | 每隔 N 天提醒一次，每次都固定在 13:52 这个时刻 |
| 每天 | 每天 13:52 提醒 |
| 每周 | 每周 周一、周三、周五 的 13:52 提醒 |
| 每月 | 每月 31 日的 13:52 提醒（该月没有 31 号时用当月最后一天） |
| 指定月份 | 每年 3、6、9、12 月的 15 日 13:52 提醒 |

**窗口太挤看不清？** 这两个窗口（设置提醒 / 设置）都可以**拖动窗口边缘放大**，里面所有文字和控件会等比跟着放大，最大 2.6 倍。缩到原大小为止，不能再小。

## 4. 到点提醒

弹窗会置顶显示原图，顶部写明触发时间、距截图已多少天、以及你的备注。

### 4.1 看图操作

| 操作 | 效果 |
|---|---|
| 滚轮 | 以**光标为中心**缩放（10%–800%） |
| 按住左键拖动 | 平移画面 |
| 双击 | 在「1:1 原始像素」与「适应窗口」之间切换 |
| `+` / `-` | 阶梯缩放 |
| `0` | 适应窗口 |
| `1` | 1:1 原始像素 |
| `R` | 顺时针旋转 90° |
| `←` / `→` | 同一条提醒链的上一张 / 下一张 |

> 磁盘上的原图永远是原始像素，从不压缩、从不覆盖。缩放只发生在屏幕上。

### 4.2 三个出口

| 按钮 | 结果 |
|---|---|
| **已知晓 / 已完成** | 本次提醒结束；若设了重复规则，自动排定下一次 |
| **稍后提醒 ▾** | 5 / 15 / 30 / 60 分钟后，或自定义分钟数 |
| **设置下一次提醒** | 打开设置面板，预填上次的规则，改完就是下一条（同一个原图，不复制文件） |

> 点右上角关闭、或按 `Esc`，等于**稍后提醒 15 分钟**（分钟数可在设置里改）。这样不会因为误点把提醒弄丢。
> 如果想强制自己面对，把弹窗强度改成「全屏遮罩」，那时没有关闭按钮，必须选一个出口。

## 5. 任务列表

双击托盘图标，或托盘右键 →「任务列表」。

- 每行显示：缩略图、备注、下次提醒时间、重复规则、状态
- **过期未处理的会标红**
- 双击某行 → 打开原图大图查看
- 右键某行 →

| 菜单项 | 说明 |
|---|---|
| 打开图片 / 打开所在文件夹 | 定位到磁盘上的原图 |
| 立即提醒 | 不用等，现在就弹 |
| 编辑提醒时间… | 改时间、改重复规则、改备注 |
| 稍后提醒 15 分钟 | 顺延一次 |
| 跳过下一次 | 重复任务跳到下一个周期（本次不处理） |
| 删除这条提醒 | 只删提醒，不删图片文件 |

顶部工具条：日历视图 / 设置 / 暂停全部 / 全部顺延 1 天 / 备份 / 刷新 / 显示已完成。
底部一行统计：待提醒数量、近 30 天提醒次数、已知晓次数、按期完成率。

## 6. 日历视图

托盘右键 →「日历视图」。

- 月历上带小圆点的日子就是有待提醒的日子，右下角数字是条数
- 点某一天，右侧列出当天所有提醒（时间 + 备注）
- 双击右侧条目，跳到任务列表对应行
- 左上 `‹` `›` 翻月，右上「回到今天」

## 7. 设置

托盘右键 →「设置」。窗口可拖动边缘放大（内容等比缩放）。

| 项目 | 说明 |
|---|---|
| 截图快捷键 | 点「录制新快捷键」，然后**直接按你想用的键**：Ctrl+Alt、Ctrl+Alt+S、A+S、Ctrl+Shift+F1 都行，最多 4 个键。按完点「完成录制」或回车确认，Esc 取消。<br>程序会自动选实现方式：<br>· 「Ctrl/Alt/Shift + 一个字母」→ 系统注册，最稳，能事前检测是否被占用<br>· 多字母组合（如 A+S）或纯修饰键（如 Ctrl+Alt）→ 键盘钩子，个别游戏反作弊/安全软件可能拦截，且无法事前检测占用，保存时会提示 |
| 提醒弹窗强度 | 普通置顶 / 强制置顶+任务栏闪烁 / 全屏遮罩 |
| 免打扰时段 | 例如 `23:00` 至 `08:00`。时段内到点的提醒**自动顺延到时段结束**，不弹窗 |
| 截图后自动复制到剪贴板 | 默认开启 |
| 默认提前预提醒 | 新建提醒时的默认值 |
| 关闭弹窗默认顺延 | 默认 15 分钟 |
| 下班时间 | 「下班前提醒」用的时刻，默认 `18:00` |
| 开机自动启动 | 在你账户的「启动」文件夹放一个快捷方式（不写注册表）。文件夹被搬走后会自动修复指向 |
| 主界面密码 | 打开任务列表 / 日历 / 设置需输密码。**只锁界面，不加密图片** |
| 数据 | 打开数据目录 / 立即备份 / 从备份还原 / **更改位置**（把现有数据复制到新盘，原位置不删） |

## 8. 文件结构

**程序**和**数据**分开放，桌面不会越堆越乱。

程序目录（exe 放哪就在哪，只有这几样）：

```
任意位置\
├─ 截图提醒.exe                 主程序（单文件，内置运行库）
├─ 截图提醒-数据位置.txt         首次启动后生成，只有一行：数据放哪
└─ docs\                        本文档（可以不放，不影响运行）
```

数据目录（首次启动时你选的盘，默认 `<盘>:\截图提醒`）：

```
D:\截图提醒\
├─ data\
│  ├─ config.json               设置（含密码哈希）
│  ├─ tasks.json                提醒任务（自动保留 tasks.json.bak）
│  └─ history.jsonl             操作历史，一行一条
├─ shots\                       原图，PNG 无损，按年月分目录
│  └─ 2026-11\
│     ├─ 20261116_112643_001.png       最终图（含标注）
│     └─ 20261116_112643_001.orig.png  仅标注过才有：未标注原图
├─ backups\                     一键备份产出的 zip
└─ logs\                        按天日志，自动保留 14 天
```

命名规则：截图 `年月日_时分秒_序号.png`，月份目录 `2026-11`，日志 `2026-11-16.log`。

**备份与迁移**

- 换电脑：拷走 `截图提醒.exe`，运行后重新选一次盘；把旧数据目录里的 `data` 和 `shots` 拷到新位置即可。
- 只说备份：设置 → 数据 → 立即备份，生成一个 zip，丢哪都行。
- 想整体搬位置：设置 → 数据 → 更改位置…，程序会复制过去并切换，原位置的文件保留不删。

## 9. 常见问题

**Q：按了快捷键没反应？**
A：多半是组合键被别的软件占了。进「设置 → 录制新快捷键」，换一个；录制时会自动检测冲突并提示。也可以运行诊断（见第 10 节）看「快捷键可注册」这一项。

**Q：截图里有程序自己的窗口？**
A：截屏前会自动隐藏抢焦点的窗口。如果本程序窗口在最前面且没被隐藏，先最小化再截图。

**Q：高分屏（缩放 150%/200%）下框选位置对不上？**
A：截图走的是物理像素路径，正常不会偏。若真遇到，运行诊断模式，把 `logs\selfcheck_*.txt` 发我，里面记录了虚拟桌面尺寸与抓取尺寸。

**Q：电脑睡眠期间到点的提醒会怎样？**
A：不会弹。唤醒后程序会检测到时间跳跃，把漏掉的那次**补弹一次**（同一条不会连环炸屏）。

**Q：为什么弹窗关掉是「稍后提醒」而不是「知道了」？**
A：防止误关导致提醒丢失。想彻底处理必须点「已知晓」。这个默认分钟数可以在设置里改。

**Q：杀毒软件报警？**
A：单文件自解压程序 + 全局热键，国内外杀软都容易误报（PyInstaller/.NET 打包的通病，不是本程序独有）。加信任目录即可，或把整个文件夹加入白名单。

**Q：忘记主界面密码了？**
A：用记事本打开 `data\config.json`，把 `passwordHash` 和 `passwordSalt` 两行值改成 `null`，保存重启即可。设置会保留，其它数据不受影响。

**Q：数据文件坏了怎么办？**
A：程序会自动用 `tasks.json.bak` 恢复；坏文件会被改名成 `*.corrupt_时间戳` 留作证据。若两个都坏，会以空数据启动并在日志里记一笔。

**Q：原图被我自己删了/移走了？**
A：弹窗会显示「原图已丢失」但不崩，你仍然可以点「已知晓」把这条任务结束。

**Q：占磁盘吗？**
A：1080p 全屏 PNG 约 0.2–2 MB/张，4K 约 2–8 MB/张。程序不自动删图，`shots\` 按年月分目录，按目录手动清理即可。

**Q：换电脑怎么办？是不是只带 exe 就行？**
A：是。只带 `截图提醒.exe` 就能在新电脑跑（自带运行库，不用装任何东西），启动后重新选一次盘。
要把老截图带过去，就把旧数据目录里的 `data` 和 `shots` 两个文件夹拷到新位置。

**Q：exe 旁边那个「截图提醒-数据位置.txt」能删吗？**
A：能。删掉后下次启动会重新问你数据放哪，已有数据不会丢（在原位置等着）。它只是一个几十字节的指路牌。

**Q：我选了 C 盘，会不会把系统盘塞满？**
A：不会自动塞满，但截图确实会长大。建议选数据盘（如 D:），或之后用「设置 → 数据 → 更改位置」搬走。

**Q：快捷键能不能用 Ctrl+Alt 这种没有字母的组合？**
A：能。录制时依次按下 Ctrl、Alt，再点「完成录制」即可（至少两个键）。
但这类纯修饰键组合要过键盘钩子，而且别的软件里按 Ctrl+Alt 也会触发截图，日常建议用「Ctrl+Alt+一个字母」这种。

## 10. 诊断模式

遇到说不清的问题时，在命令行执行：

```
截图提醒.exe --check
```

不会弹界面，会在 `logs\` 下生成 `selfcheck_年月日_时分秒.txt`，逐项列出：目录是否可写、配置能否读写、任务数据条数、快捷键能否注册、能否抓屏（含虚拟桌面尺寸）、PNG 存取一致性、开机自启状态。有问题的那项会标 `FAIL`。

## 11. 隐私与边界

- **完全离线**：不联网、不上传、无账号、无云同步
- **不加壳、不常驻服务**：只有一个前台进程 + 托盘图标
- **全部数据在本目录**：删掉文件夹 = 彻底卸载，无残留
- **密码只锁界面**：`shots\` 里的 PNG 是明文，任何人拿到文件夹都能看
- **「任意两键」模式**需要键盘钩子，个别游戏反作弊或安全软件会拦截，且无法事前判断是否被占用。日常建议用默认的 `Ctrl+Alt+S` 这类组合
